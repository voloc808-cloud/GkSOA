# Backend Lumen

Đăng nhập và cấp quyền: xem [hướng dẫn tài khoản](../docs/accounts.md). Admin quản lý tài khoản trong mục **Tài khoản** trên frontend.
Ba module SinhVien, DeTai, DangKy có controller, validation, model và service riêng.
SERVICE_MODULE xác định module được công bố: all, sinhvien, detai hoặc dangky.
Triển khai SOA dùng ba tiến trình từ cùng bộ mã; xem README gốc và docs/architecture.md.
